# A note for Lee

This project was inspired by a small neural-network program written by
Lee Atkins in 1996 and preserved on Aminet.

The original source is not redistributed here. The implementation in this
repository is new, and the historical program is credited only as the spark
that led to the Three Plus One experiment.

One old AMOS-list signature asked why fish do not have beards.

If Lee Atkins ever finds this repository:

> If you're still wondering why fish don't have beards: Japanese koi do.
> They have barbels — whisker-like sensory organs around the mouth.

Thirty years later, that question finally has at least one answer.
