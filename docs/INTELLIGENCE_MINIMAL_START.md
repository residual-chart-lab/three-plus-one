# 3+1：知性の運動の最小模型への出発点

2026-10-11。基準：508a113aeb13c2bf94cee8002992aeade2e4622c（draft PR #15）。
既存稿を保存したまま、別ブランチで進める。

**目標：通過で生じた差が保持され、次の応答へ使われる運動を、既存の3+1から絞り出す。**

## 最初の検査

既存の順序付きXNOR学習を728 epochまで進め、等しい二ユニットを逆向きに変える四成分の接空間を調べた。入力値・教師値・提示順・学習率は全条件で同じ。

一更新で運ばれた微小差を、現在の位相に見える成分と見えない成分に分ける。見えない成分を保持／消去／元に戻す三条件で、次の同じ四標本への応答を比較した。

| 条件 | epoch 729の位相応答 | epoch 730の位相応答 |
|---|---:|---:|
| 保持 | 0.999491799653662 | 0.998989829102497 |
| 消去 | 0.999491799653662 | 0.998986959696541 |
| 復元 | 0.999491799653662 | 0.998989829102497 |

**現在の位相応答が同じでも、保持と消去の次応答は約2.8694059569e-6異なる。**

差を復元すると元の応答に戻る。復元は介入の健全性を確かめる対照であり、それ自体を新しい作用の発見とは数えない。

実際の非線形ネットワークに±の摂動を与える中心差分でも確認した。振幅1e-3で、保持と消去の応答差は2.8694053975e-6。接空間の予測との差は約5.6e-13。振幅1e-2,1e-4でも検査した。

これは今回独立に考案した新しい記憶則ではない。既存のSGDで生じるhidden-returnを、短い介入実験へまとめ直した結果。

## 数理的な範囲

基準軌道の残差をR、位相読出しをℓ(v)=Rᵀv/‖R‖²、既存の接写像をJとする。
一巡で v'=JR=ρR'+h が生じ、ℓ'(h)=0。
次の一巡で ℓ''(J'v')=ρρ'+ℓ''(J'h)。最後の項が保持と消去の差である。

- 今回の数値は位相の局所微分。有限振幅のネットワーク出力が厳密に同じという主張ではない。
- 基準軌道を別に与える四成分接空間についての検査。四成分だけの自律的な完全ネットワークを得たわけではない。
- 既存のrank-four結果も、指定軌道・読出しに対する正確な線形保持次元の主張。知性一般の最小次元、四ユニットの必要性を証明しない。
- 「帰還」は隠れ成分の位相への再出現。全状態の周期帰還・参照帰還とは区別する。
- 今回はbinary64の診断。既存の区間演算による証明は別の根拠として残す。

## 当初の次段階案（同日、方針を修正）

残す核は、**通過 → 差の保持 → 後続応答の変化**。
既存の三重対称な二次項と方向選別は、その先へ接続する候補として維持する。

> 方針更新：知性は完成後の読みとして置き、課題成績を模型の合格条件にはしない。まず一周を繰り返せる形へ整理する。[動く一周の反復](INTELLIGENCE_MOTION_LOOP.md)を現在の入口とする。以下は当初案として保存する。

当初の提案は、**その差が課題に沿った応答に実際に寄与するか**を次に調べることだった。
応答が変わることだけでは知性としての実効性は判定できない。

1. 入力・教師値・基準状態・計算予算を固定する。
2. 既存の運動で生じた差を保持／消去して比較する。
3. 評価する課題と読出しを先に決める。位相への復帰と課題成績を混同しない。
4. 差の配置を交換する対照も置き、単なる大きさや追加計算の効果と分ける。
5. 有益・無効・有害のいずれも記録する。

自発的な分岐、目標や意味の生成、転移能力は未検査。
最小模型の完成宣言ではなく、知性の運動として絞るための作業開始版である。

## 他の理論との位置

共通最小モデルは比較の原理、自由数は必要な保持・輸送を調べる道具として使う。3+1の成立理由として両者を仮定しない。

未来拘束Cは保護仮説として別に維持する。今回の教師値や誤差関数をTime EngineのCと同一視しない。未来因果を除去した完成や代替機構を主張する試験ではない。

漸近locking、四階差分の極限、独立したローター模型は研究履歴に残す。短い検査の入口へ全部を詰め込まない。
