# 3+1 知性の最小モデル v1

2026-10-12 / 動く概念実証の基準版

**違いに応じ、経験の差を持ち越し、その差で次の応じ方を変える。**
この一周を既存の3+1の運動で見せる、「知性の最小モデル」としてv1を固定する。
ここでの最小は、この三つの働きに焦点を絞った最小構成を指す。知性一般の最小次元の定理ではない。

## まず、これだけを読む

四つの接触にそれぞれ応じる。同じ接触を一巡すると、現在の位相からは見えない差が残る。
次の一巡では、その差も動き、どの接触へどう応じるかを変える。応じた結果はまた差として残る。

```mermaid
flowchart LR
    A[接触の違い] --> B[応答する]
    B --> C[見えない差が残る]
    C --> D[次の応答へ運ぶ]
    D --> E[入力への応答関係が変わる]
    E --> B
```

「区別する」「持ち越す」「区別の仕方が変わる」を別々の装置として足す必要はなかった。
ここでは元の学習運動を、その三つが見える形へ分けている。

## 3+1の中身

現在の可視な位相を一つの数yで読む。その読出しから見えない差hには三つの独立な方向がある。
合わせて、元の四成分の局所変化vになる。

$$v=yR+h,\qquad \ell(h)=0,\qquad \ell(R)=1.$$

一巡の既存接写像をJ、次の基準方向をR⁺とすれば、

$$y^+=\rho y+\ell^+(Jh),\qquad \rho=\ell^+(JR),$$

$$h^+=(JR-\rho R^+)y+Jh-\ell^+(Jh)R^+.$$

最初の式は、以前から見えている位相と、保持差から戻った分が次の位相を作ることを表す。
二つ目は、今回生じた差と、以前から持ち越した差が、次の保持差を作ることを表す。
この二式は既存の学習則の分解。新しい記憶係数や分類規則は学習へ足していない。

基準ネットワークqの17個の重み・バイアスも一緒に更新する。3+1はその上で追う「三つの保持方向＋一つの位相」であり、四個の数だけでネットワーク全体が自律動作するという意味ではない。

## 記憶があれば、区別が変わるのか

いつもそうなるわけではない。**残った差が、次の接触を別の関係で受け取る方向へ効くこと**が必要になる。

同じ現在状態から四つの接触を独立に調べる。応答をまとめる行列をA、全入力に共通のずれを除く操作をPとする。
消去時の応答はb=PA(yR)、保持差からの応答はd=PAhとなる。

$$d_\perp=d-\frac{b^\mathsf{T}d}{b^\mathsf{T}b}b.$$

**d⊥が残れば、応答の全体倍率と共通ずれだけでは保持と消去を一致させられない。**
これは今回の「区別の仕方が変わる」の短い条件である。bが0でない場合の局所線形応答について述べている。
Pは入力平均を引く操作。Aの各行は、接触前に固定した同じ読出しによるℓ_q(K_x−I)。入力ごとに読出しの軸を替えていない。
αbへまとめられる差は、ここでは新しい区別とは数えない。

## 動く例

XNORの四標本00→1、01→0、10→0、11→1に接触する既存模型を使った。
開始時点を三つ、学習の入力順を三つに変え、それぞれ8周の保持を調べた。
入力番号は0=00、1=01、2=10、3=11。各条件の基準学習の履歴もその順序で作る。
途中で順序を切り替える試験ではなく、それぞれ別の学習履歴から始める試験である。

| 開始epoch | 入力番号の順序 | 8周後、倍率・共通ずれで説明できない相対残差 |
|---:|---|---:|
| 100 | 0→1→2→3 | 0.3624% |
| 100 | 3→2→1→0 | 0.2163% |
| 100 | 0→2→1→3 | 0.3624% |
| 400 | 0→1→2→3 | 0.5401% |
| 400 | 3→2→1→0 | 0.5221% |
| 400 | 0→2→1→3 | 0.5401% |
| 728 | 0→1→2→3 | 5.9492% |
| 728 | 3→2→1→0 | 5.4879% |
| 728 | 0→2→1→3 | 5.9492% |

**今回調べた9条件すべてで、この応答関係の変化が出た。**
百分率は入力別の応答パターンの残差であり、正解率や知性の点数ではない。隣の入力01と10の順を交換した二条件は対称性が強く、独立した九つの証明とは数えない。
代表例epoch 728・元の順序は約5.95%。教師値を読まない内部活性差でも約2.20%が残った。
代表例については、元の非線形ネットワークへ±の小摂動を与える中心差分で確認済み。九条件すべての独立な非線形確認までは広げていない。

## 壊れる例も残す

各時点で、実際に生じたhと同じ大きさを持ち、現在の位相からは見えない別方向の差を診断用に作った。
その差はd⊥=0となる方向を選ぶため、**差が残っているのに、今回の読出しでは区別が変わらない。**
この方向は比較のために作った対照で、学習運動に追加した装置ではない。
同ノルム対照の相対残差は全条件・全時点で最大6.17e-16。上の条件式と実測残差の一致誤差は最大3.26e-16だった。
差の有無や大きさだけでは、知性のこの働きを説明できない。差がどこへ効くかまで見る必要がある。
この対照が見えないのは今回の四接触・読出しに対してであり、将来のあらゆる接触に無効と証明したものではない。

## v1の合格ライン

| 働き | この模型で見せられること |
|---|---|
| 区別する | 同じ状態からの異なる接触に、異なる内部応答を返す |
| 持ち越す | 接触で生じた差が次の一巡へ運ばれ、応答へ戻る |
| 区別の仕方が変わる | 保持差により、入力間の応答関係が一様な増幅以上に変わる |

このラインで、**3+1を知性の運動の最小モデルとして使い始める。**
相手の違いを受け取り、経験を残し、その経験によって受け取り方を変える、という働きを、動く一周で教えられる。

今回の反対称な局所摂動では外部出力の一次変化は打ち消されるため、実用的な分類境界や成績の改善はこのv1の主張に含めない。
自由数と共通最小モデルは比較の足場として保つ。Time Engineの未来拘束Cは別に保持し、今回の教師値や誤差関数と同一視しない。
今回のv1は、この動作を伝える概念実証の基準版である。知性一般の完成宣言、厳密な最小性、未来因果の導出を要求して完成を止めない。
